Europe, Australia, Africa, US Web Vitals Summary

Regions: Europe, Australia, Africa, US

Overall performance insights

The Africa-region test shows generally good backend responsiveness, with TTFB behavior indicating the server is responding quickly in most cases. User interaction readiness is strong, but page rendering and full load metrics indicate room for improvement.

  • Strong: TTFB median ~70ms, indicating good backend response times.
  • Strong: TTI median ~498ms, showing pages become interactive quickly.
  • Needs work: LCP average ~415ms, above the recommended 250ms threshold.
  • Needs work: Average page load time ~4.9s, which is high for modern web expectations.
  • Needs work: Average page weight ~4.18MB, with the landing page spiking to over 13MB.

Key recommendations

  • Reduce landing page payload. The Main Landing Page is heavy at ~13MB; optimize images, fonts, and third-party assets first.
  • Improve LCP and FCP. Prioritize visible hero content, critical CSS, and early asset delivery to lower the 415ms average.
  • Fix layout shift on the landing page. Reserve size for images and embedded content to reduce the 0.255 CLS average.
  • Audit page weight. Overall average page size ~4.18MB suggests further compression and lazy-loading can help full load time.
  • Investigate TTFB outliers. Most responses are fast, but occasional spikes above 1s indicate regional cache or backend path issues.
  • Capture more INP data. Only 17 interaction metrics were present; broadening interaction measurement will validate responsiveness across more user journeys.

Conclusion

The Africa-region experience is promising for server response and interactivity, but the page loading experience is currently held back by larger payloads and slower first-content rendering. Focus on the landing page first and keep the smaller pages as benchmarks for what a better experience can look like.
