🔍 Key Findings
Critical
CLS Failure on Main Landing Page (0.2881 — Poor)
The Main Landing Page records CLS = 0.2881 in the vast majority of runs across all four global regions. The Google CWV threshold for Poor is >0.25. This is a Core Web Vitals ranking signal failure that will suppress organic search visibility. The layout shift is likely caused by late-loading above-the-fold images, hero banners injected after initial render, or fonts causing text reflow.
Critical
Africa Run 2 Anomaly — Browse Products Timeout (~20s)
Africa session recorded an LCP of 19,928ms and TTFB of 19,791ms for Browse Products in Run 2, indicating a near-complete network timeout or extreme latency spike during that transaction. All other runs were normal. This should be investigated as a potential CDN failover or transient routing issue affecting the Africa South PoP.
Warning
Africa Cold-Start TTFB Near Threshold (765ms)
Africa Run 1 recorded TTFB = 765ms on the Main Landing Page — within 35ms of the 800ms "needs improvement" boundary and with LCP of 1,172ms. Subsequent runs improved dramatically (<250ms TTFB). This indicates the CDN or origin server is not pre-warmed for the Africa South region, penalising first-time visitors.
Warning
Page Load Times Above 2s Target in All Regions
All four regions exceed the ideal 2-second page load benchmark for the Main Landing Page: US East 3,021ms, EU West 2,612ms, Australia 4,057ms, Africa 6,048ms. The progressively worse performance in distant regions confirms the site relies heavily on origin-served content rather than fully CDN-distributed assets, and the high page weight (~13MB in prior test data) is a major contributor.
Warning
Browse Products CLS at 0.1216 — Needs Improvement
The Browse Products page records CLS = 0.1216 in essentially every warm run across all regions. This falls in the "Needs Improvement" band (0.1–0.25). It is consistent with Browse Products and Digital IP Management sharing the same DOM (anchor navigation). The fix applied to the landing page should be extended to this page's product grid as well.
Positive
LCP and INP Pass Globally — Strong Loading & Interactivity
After warm-up, LCP averages 308–480ms globally — well under the 2,500ms Good threshold. INP averages 33–82ms globally, far below the 200ms Good threshold. FPS is a consistent 60fps in every region. These results demonstrate excellent responsiveness and perceived loading speed once CDN cache is warmed.
Positive
TTFB Excellent in EU, US, and Australia
EU West (38ms), Australia (27ms), and US East (46ms) all show exceptional TTFB on warm runs, indicating well-configured CDN edge caching in these regions. Australia's TTFB of 27ms is particularly impressive given its geographic distance from the US origin, suggesting effective edge caching at Sydney PoPs.
Informational
CLS Score is Deterministic — Not a Fluke
The CLS score of 0.2881 on the Main Landing Page appears in virtually every run after the first in all four regions. This consistency confirms the layout shift is a reproducible, structural issue tied to the page's render sequence — not a transient CDN or network artefact. It will affect real users at the same rate regardless of geographic location.
✅ Prioritised Recommendations
P1 Critical
Fix CLS on Main Landing Page (perforce.com/)
Add explicit width and height attributes to all above-the-fold images and hero elements. Defer or preload fonts to prevent text reflow. Avoid injecting banners, modals, or sticky headers above content after initial render. Target: CLS ≤ 0.1 (Good).
P1 Critical
Fix CLS on Browse Products page (perforce.com/products)
Same root cause as the landing page. Product card images and lazy-loaded content below the fold are causing layout shift at 0.1216. Apply explicit image dimensions and reserve space for dynamically injected product tiles. Target: CLS ≤ 0.1.
P2 High
Investigate Africa Browse Products timeout (Run 2, ~20s latency)
The 19,928ms LCP / 19,791ms TTFB event in Africa Run 2 suggests a CDN failover, origin routing failure, or BGP instability event. Review CDN provider logs for the africa-south1-a PoP around 2026-05-26 15:30 UTC to determine root cause and whether a failover or origin health-check policy change is needed.
P2 High
Pre-warm CDN cache for Africa region / reduce cold-start TTFB
Africa Run 1 TTFB of 765ms is near the 800ms threshold, and LCP of 1,172ms is the highest of any warm-state region. Implement CDN cache pre-warming for africa-south1-a, or consider an additional PoP closer to South Africa. Alternatively, configure longer cache TTLs for static assets in this region.
P3 Medium
Reduce page load time for Africa and Australia (>4s)
Africa averages 6,048ms and Australia 4,057ms for the Main Landing Page. The primary lever is payload reduction (see prior test showing ~13MB page weight). Enable aggressive asset compression (Brotli), implement lazy-loading for below-the-fold images, and ensure all static assets are served from the nearest CDN edge node rather than origin.
P3 Medium
Set up automated CWV failure criteria in BlazeMeter
Configure test failure criteria for CLS > 0.1 on the Main Landing Page and Browse Products steps so future test runs automatically flag regressions. Recommended thresholds: LCP > 2,500ms (fail), CLS > 0.1 (fail), INP > 200ms (fail), TTFB > 800ms (warn).
